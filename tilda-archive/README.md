# Архив сайта mogosh.ru с Tilda

Скачано 21.11.2026 из проекта Tilda «Ведущий Михаил Могош» (id 32501).

- `files/` — все 177 картинок проекта в оригинальном качестве. Имя файла: `<id папки на Tilda>__<исходное имя>`.
- `pages/` — сохранённый HTML опубликованных страниц (main, страницы пар, corporate, header, footer) и блок отзывов с неопубликованной страницы feedback.
- `all-urls.txt` — исходные адреса файлов на static.tildacdn.com.

Видео на старом сайте были встроены с Vimeo (файлов на Tilda нет): id 307651316, 317967499 и др. — см. pages/.

Новый сайт (`index.html`) берёт картинки из папки `img/` — это сжатые копии нужных файлов отсюда.
